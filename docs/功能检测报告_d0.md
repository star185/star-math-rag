# Star Math 智能问答系统功能检测报告

（用户视角 · 2026 年 10 月 14 日）

# 摘要

本报告以真实用户操作视角，对毕业设计项目 Star Math（基于 RAG 的数学知识库智能问答系统）进行了完整的功能检测。检测分三层进行：项目自带冒烟测试 8 项、自编 API 全流程检测 42 项、浏览器真实界面操作（智能问答、知识库、测试评估、练习四个面板及核心流程），共覆盖认证与权限、RAG 问答、会话管理、知识库管理、检索调试、测试题集、做题练习、评测八大模块。

检测结论为：系统功能完整可用，三层检测全部通过，未发现阻断性缺陷。RAG 问答能正确返回带知识库来源的流式回答，数学公式渲染正常；对知识库未覆盖的问题（如拉普拉斯展开定理）系统诚实回答“无法根据现有资料确定”，未发生编造，防幻觉行为符合预期。权限控制完善，普通用户的越权上传、删除操作均被服务端拦截。

同时发现两处次要界面问题：浏览器窗口宽度小于 960 像素时，侧边导航栏（知识库、测试评估、练习入口）被样式隐藏且无替代入口，窄窗口下用户无法切换功能面板；网站缺少 favicon 图标。建议在答辩演示前处理上述两项小问题，并确认 LLM 网关令牌在有效期内。

# 1 检测概述

## 1.1 背景与目标

Star Math 是面向数学领域（数学分析、线性代数、概率统计）的 RAG 智能问答系统，后端为 FastAPI，前端为原生 Web 页面，通过 LLM 网关接入大模型。本次检测的目标是从真实用户的使用路径出发，逐项验证系统登录、问答、会话、知识库管理、检索、做题、评测等核心功能是否可用，并定位影响演示体验的问题。

## 1.2 检测环境

· 服务：后端 http://127.0.0.1:8000（运行中），LLM 网关 :4096（运行中）。

· 知识库基线：110 篇文档 / 323 个知识片段，模块分布为分析 72、线性代数 21、概率统计 17。

· 配置：Embedder 为 LocalEmbedder，LLM 已配置，Top-K 5，Chunk 500 / overlap 50。

· 测试题集：100 题（难度 L1 34 / L2 33 / L3 33；模式 short 76 / choice 14 / calc 10）。

· 演示账号：admin / admin123（管理员）。

## 1.3 检测方法与数据清理

检测按三层执行：第一层运行项目自带冒烟脚本 smoke_test.py；第二层运行自编的用户视角 API 全流程脚本，覆盖登录注册鉴权、SSE 问答、会话管理、知识库上传与检索与删除、检索调试、题集读取、做题判分与记录导出、评测执行与记录；第三层通过浏览器实际操作页面，验证界面交互与数据展示。检测过程中产生的测试文档、测试会话、做题记录、评测记录与注册账号，均已在交付前清理，知识库恢复至原有 110 篇，不影响正常使用。

# 3 分模块检测结果

## 3.1 认证与权限控制（9/9 通过）

登录、注册、鉴权与权限隔离行为全部符合预期：正确口令登录成功并返回令牌；错误口令返回 401 且提示“用户名或密码错误”；重复用户名注册返回 400；未登录访问受保护接口返回 401；普通用户上传、删除文档均被服务端以 403 拒绝，但可正常浏览知识库列表，权限边界清晰。

## 3.2 RAG 问答（3/3 通过）

分别以数学分析、线性代数、概率统计三模块的典型问题（数列极限的 ε-N 定义、矩阵的秩、条件概率与贝叶斯公式）提问，均通过 SSE 流式返回完整回答，并附 5 条知识库来源、来源文档与相似度评分；回答中的数学公式在界面中正确渲染。补充验证防幻觉能力：提问知识库未覆盖的“拉普拉斯展开定理”时，系统明确说明无法依据现有资料作答，未生成虚构内容，符合 RAG 系统的可靠性要求。

## 3.3 会话管理（6/6 通过）

会话创建、带会话编号的连续追问、历史消息（含用户与助手往返）读取、会话列表、重命名与删除全部正常，历史消息按时间顺序正确返回。

## 3.4 知识库管理（10/10 通过）

知识库上传闭环完整可用：上传 Markdown 文档后完成解析、frontmatter 读取、切分、入库与向量化；新文档可通过检索调试接口定向命中；文档下载字节数与原文一致；正文预览正常；同名文档重复上传被 409 拒绝；管理员删除后检索不再命中；普通用户删除被 403 拦截。管理端界面正确显示 110 篇文档、323 个片段及模块统计，文档预览模态框支持“完整原文 / 分块视图”切换。

## 3.5 检索调试（3/3 通过）

混合检索（hybrid）对正常问题命中 5 条相关内容；对无意义噪声串返回 0 命中，未出现误召回；关键词模式（keyword）检索同样正常。

## 3.6 测试题集（2/2 通过）

测试题集接口返回 100 题，结构完整，每题均含难度（L1/L2/L3）与模式（choice/judge/short/calc）等字段，可按模块、题型、难度、知识点筛选抽题。

## 3.7 做题练习（7/7 通过）

做题全链路可用：按模块抽题生成 5 道题（含选择题与简答题混合）；选择题本地比对判分正确；简答题由 LLM 判分并给出要点反馈；查看解析可展开参考答案要点与计算步骤；答题记录自动保存并进入错题本；按模块与“只看错题”筛选、Markdown 导出均正常。

## 3.8 评测（2/2 通过）

单题评测接口可执行 RAG 作答，返回回答、来源与延迟（实测约 1.1 万毫秒，主要为 LLM 生成耗时）；评测记录列表正确保存并展示历史记录。

# 4 发现的问题与改进建议

检测未发现影响核心功能的阻断性缺陷。以下 4 项为次要问题或运维注意事项，按优先级列于表 2。

表 2　问题清单与改进建议

| 编号 | 问题 | 影响 | 建议 | 优先级 |
| --- | --- | --- | --- | --- |
| 1 | 窗口宽度 <960px 时侧边导航栏被隐藏，且无替代导航入口 | 窄窗口下无法切换到知识库、测试评估、练习面板 | 补充汉堡菜单或底部导航，使窄屏下仍可切换面板 | 中 |
| 2 | favicon.ico 缺失（404） | 浏览器标签页无网站图标，观感不完整 | 在 frontend 静态目录补充 favicon 图标 | 低 |
| 3 | 知识库未覆盖部分线性代数主题（如拉普拉斯展开、行列式按行展开） | 此类问题会回答“无法确定”，覆盖度有缺口 | 如需可补充对应语料文档；当前行为属防幻觉正常表现 | 低 |
| 4 | LLM 网关令牌有效期 24 小时 | 令牌过期后问答返回 401，影响答辩演示 | 答辩前按 README 执行令牌续期并重启后端 | 运维 |

其中第 1 项建议优先处理：毕业设计答辩现场若使用笔记本小窗口或投影较低分辨率演示，可能出现导航不可见的情况，影响知识库与做题功能的现场展示。第 4 项为答辩前的必查项，需确认网关令牌在有效期内。

# 5 结论

Star Math 系统各功能模块实测可用，满足毕业设计开题报告中“领域文档与测试集、知识库管理、语义检索与 RAG、Web 界面、测试方案、大模型接入”六项课题要求，可作为答辩演示版本。建议在正式演示前完成窄屏导航与 favicon 两项小优化，并确认 LLM 网关令牌有效；如希望覆盖更多线性代数知识点，可补充相应语料后重建向量库。
